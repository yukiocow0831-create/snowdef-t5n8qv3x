# 同窓会アンケートの受け口（Google Apps Script）

クラスの回答は、Googleスプレッドシートにたまります。ページは `dousoukai/index.html` です。

## 1. スプレッドシートを作る

1. Googleドライブで、新しいスプレッドシートを作ります。
2. 名前は「同窓会アンケート 2027」などで構いません。
3. メニューの **拡張機能** → **Apps Script** を開きます。
4. 開いたエディタの `コード.gs` を、このフォルダの `Code.gs` の中身ですべて置き換えます。
5. 保存します（フロッピーのアイコン、または Ctrl+S / ⌘S）。

シート `options` と `votes` は、最初の実行で自動的にできます。列の名前は変えないでください。

## 2. 最初のデータを入れる

1. Apps Script の関数一覧で **setup** を選びます。
2. **実行** を押します。
3. 初回だけ、権限の確認が出ます。自分のGoogleアカウントで許可します。
4. スプレッドシートに戻り、`options` に会場・日程・ゴルフの候補が入っていることを確認します。

もう一度 setup を実行しても、すでに候補があれば足しません。

## 3. ウェブアプリとして公開する

1. Apps Script 右上の **デプロイ** → **新しいデプロイ**。
2. 歯車アイコン → **ウェブアプリ**。
3. 次のとおりにします。
   - **説明**: 同窓会アンケート
   - **次のユーザーとして実行**: **自分**
   - **アクセスできるユーザー**: **全員**
4. **デプロイ** を押します。
5. 表示された **ウェブアプリのURL** をコピーします。`https://script.google.com/macros/s/` で始まり、`/exec` で終わります。

URLを直したあとは、**デプロイ** → **デプロイを管理** → 鉛筆アイコン → **バージョン: 新バージョン** → **デプロイ** です。同じURLのまま中身が更新されます。

## 4. ページとつなぐ

`dousoukai/index.html` の先頭近くにある、次の行を書き換えます。

```javascript
const GAS_URL = '';
```

引用符の中に、コピーしたウェブアプリのURLを貼ります。

```javascript
const GAS_URL = 'https://script.google.com/macros/s/xxxxxxxx/exec';
```

空のままだと、ページは「準備中（テスト表示）」になり、そのスマホの中だけに保存します。

## 5. 動き

- 読み込み: `GET ウェブアプリURL?action=get`
- 保存: `POST` で、JSONを `text/plain` のまま送ります（ブラウザの事前確認を避けるためです）。
- `vote` は、同じ人・同じ候補の回答を上書きします。ゴルフの予定は、一人ひとつだけ残します。
- `voteBatch` は、一人分の回答をまとめて受け取ります。その人の以前の回答は、今回の内容に置き換わります。
- `addOption` は候補を足します。名前30文字、候補60文字、メモ100文字まで。1つの欄は40件までです。

回答に書かれた文字は、表の文字として保存するだけです。HTMLとしては表示しません。
